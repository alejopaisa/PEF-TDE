# Reference Epoch Provenance Notes

The six current repository reference epochs are literature-verified descriptive reference epochs. They are not methodologically homogeneous: the set includes bolometric, single-band, and fitted multiband definitions.

These epochs must not yet be treated as one homogeneous physical decline anchor. Absolute MJD values are not divided by `(1 + z)`.

Materially distinct published alternatives are preserved as provenance rather than treated as errors. AT2020ysg has the largest documented discrepancy in this audit: 28.32 d between the current Hammerstein-style epoch and the Yao rest-frame-g fitted epoch.

No final decline anchor has been adopted.
