# PEF-TDE
Empirical phenomenological classification framework for TDE light curves

## Repository Organization

The repository separates frozen historical artifacts from reconstruction work:

- `data/raw`, `data/processed`, and `data/metadata`: recovered historical data products and metadata.
- `data/reconstructed`: future validated reconstructed datasets.
- `results`, `tables`, and `figures`: separated into `historical`, `reconstruction`, and `final` layers.
- `scripts`: grouped by preprocessing, fitting, diagnostics, robustness, tables, and figures.
- `paper`: historical manuscript artifacts remain frozen; future reconstructed manuscript work belongs under `paper/reconstructed`.
- `docs`: reconstruction provenance, evidence registers, decisions, and workflow policy.
